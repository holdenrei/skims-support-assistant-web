SKIMS SUPPORT ASSISTANT — HOSTED KUSTOMER IMPORT SETUP

Before setup
- Deploy this repository as its own Render Web Service.
- Configure GROQ_API_KEY, GROQ_MODEL, APP_ACCESS_PASSWORD, and APP_ORIGIN in Render.
- Replace the placeholder service URL in SKIMS-Import-Bookmarklet.txt with the exact Render URL.

Bookmarklet
1. Create a Chrome bookmark named "SKIMS Import to Ticket".
2. Edit it and paste the complete one-line contents of SKIMS-Import-Bookmarklet.txt into its URL field.
3. Save the bookmark.

Import
1. Sign in to the SKIMS Support Assistant using APP_ACCESS_PASSWORD.
2. Paste the exact Kustomer conversation URL into the intended ticket and click Import conversation.
3. In the matching Kustomer tab, click the bookmarklet.
4. The bookmarklet verifies the workspace and conversation, retrieves messages and attachment details through the already-authenticated Kustomer browser session, and submits the result using a short-lived, single-use token.
5. Return to the website and review the imported history before drafting.

Security
- The Groq API key stays server-side.
- Website API actions require a private login session.
- The bookmarklet importer is read-only; it does not send replies or edit Kustomer records.
- Import jobs and login sessions live in server memory and are cleared by a service restart/redeploy.
- Never commit .env, API keys, passwords, cookies, or customer conversation data.
- Confirm employer approval before using real customer information.
